# 0009 Produkt für andere

Datum: 24.09.2026. Entschieden von: Maintainer.

- tybo ist ein Produkt für andere. Wer es auf einem nackten Rechner ausrollt,
  wird durch die Einrichtung geführt (M8).
- Name, Befehl und Domain stehen an genau einer Stelle (`src/brand.ts`):
  **tybo**, Befehl `tybo`, Domain **tybo.ai** (Entscheidung 0015). Sichtbare
  Texte nutzen diese Stelle statt fester Namen.
- tybo.ai ist für den Installations-Einzeiler und einen von außen
  abgesicherten Zugang zur WebUI vorgesehen (Entscheidung 0014). Ohne diesen
  Zugang gilt „nur im Heimnetz" (Entscheidung 0002).
